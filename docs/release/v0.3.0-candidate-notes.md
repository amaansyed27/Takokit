# Takokit v0.3.0 candidate

This unreleased candidate extends the same Takokit runtime, registry, APIs, GUI assets, and signed updater trust chain to Linux x86_64 and macOS arm64 while preserving Windows x86_64 compatibility.

- Linux installs per user under `~/.local/share/takokit`, exposes `tako` through `~/.local/bin`, and adds an optional freedesktop launcher without requiring systemd.
- macOS installs the immutable runtime per user, exposes the same CLI, and adds `~/Applications/Takokit.app` as a browser-GUI launcher without embedding a webview.
- `install.sh` verifies production metadata, HTTPS location, artifact name, SHA-256, archive paths, links, executable mode, and binary version before atomically replacing an install.
- Normal uninstall preserves `~/.takokit` and every workspace `.tako` directory.
- Platform manifests remain Ed25519 signed by the existing `takokit-release-v1` trust identity. The legacy Windows `release-manifest.json` path remains the v0.2.0-to-v0.3.0 compatibility shim.

This file describes a review candidate. It does not authorize a tag, GitHub Release, stable metadata publication, or website deployment.
