# Takokit 0.2.0 candidate — local audio API and server UX

This is development-candidate documentation, not a published release record. The stable public Windows release remains v0.1.0 until manual acceptance and an explicit release decision.

The candidate adds an OpenAI-compatible audio subset (`models`, speech, and transcription), a canonical Takokit-native `/api/v1` namespace, improved server lifecycle commands, and a lightweight Windows tray controller. It does not add chat, Responses, embeddings, images, a desktop WebView, or non-Windows packages.
