One interface

Speak. Listen. Clone. Convert.

Takokit gives very different open voice projects one predictable install, planning, execution, and storage contract.

01 / SYNTHESIZE

Text to speech

Generate local speech with compact ONNX voices or expressive neural models.

tako speak "Hello" --model kokoro
02 / TRANSCRIBE

Speech to text

Run lightweight Whisper or larger multilingual transcription families.

tako transcribe voice.wav --model whisper:small
03 / CREATE

Voice workflows

Clone, convert, and train with explicit consent and project-local evidence.

tako clone sample.wav --model chatterbox --consent

Built to reuse

One store. Shared runners.

Checkpoints remain pinned and content-addressed. Compatible models reuse the same runner contracts, heavy Python bases, Torch packages, and download caches.

Local by design

Model bytes go source → machine.

The Takokit Library is the trusted resolver, not another multi-gigabyte cache. Checkpoints download directly from pinned upstream sources and become ready only after verification.
