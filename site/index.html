Browse curated speech-to-text, text-to-speech, cloning, conversion, and audio-language families. Tags select variants; immutable digests make every pull reproducible.

A library, not another cache.

Takokit is the trusted control plane. Large checkpoints still travel directly from their pinned upstream source into content-addressed local storage.

01 / RESOLVE

Name → manifest

kokoro resolves to the current Takokit-tested tag and an immutable manifest digest.

02 / ACQUIRE

Source → local blobs

Files resume from pinned Hugging Face or release sources and verify before becoming ready.

03 / REUSE

Runner → execution

Compatible models share runners, Python bases, Torch packages, caches, and verified adapters.
