01 / Install

Build the public beta.

Takokit is currently distributed from source while signed platform installers are prepared. Install Rust stable, Node.js LTS, and Git, then build both the GUI and optimized Rust binaries.

git clone https://github.com/amaansyed27/Takokit.git cd Takokit cd apps/gui && npm ci && npm run build && cd ../.. cargo build --release

On Windows, the binaries are written to target\release\tako.exe and takokit.exe.

02 / Quickstart

Pull, inspect, run.

tako library sync tako pull kokoro tako plan kokoro tako speak "Hello from Takokit" --model kokoro

Transcription follows the same contract:

tako pull whisper:small tako transcribe ./sample.wav --model whisper:small

03 / References

Choose a family or a release.

Takokit references follow [namespace/]model[:tag][@sha256:digest].

kokoro whisper:small library/qwen3-tts:0.6b-base openvoice:2@sha256:<manifest-digest>

An omitted tag resolves to the Takokit-tested default. Legacy names remain aliases: whisper-tiny and whisper:tiny share one install ID and one set of files.

04 / Storage

Global runtime, project outputs.

Reusable data belongs to ~/.takokit; generated work belongs to the project that launched Takokit.

~/.takokit/ ├── models/ # model records and materialized artifacts ├── runners/ # shared execution runtimes ├── blobs/ # content-addressed files ├── cache/ # upstream and package caches └── manifests/ # registry cache project/.tako/sessions/ # prompts, events, audio, transcripts

05 / Pull lifecycle

Ready means verified.

A pull resolves the registry reference, runner, shared base, adapter, and pinned model artifacts. Interrupted files stay cached for recovery but are never listed as ready until the final execution plan succeeds.

06 / Voice safety

Consent is part of the command.

Cloning, conversion, and training require confirmation that the supplied voice is owned or explicitly authorized.

tako clone ./reference.wav --name "My Voice" --model chatterbox --consent tako convert ./source.wav --target-voice ./target.wav --model openvoice:2 --consent

07 / Local API

One server for every surface.

The managed daemon listens on http://127.0.0.1:5050. CLI, TUI, GUI, and API share installed state and project sessions.

GET /health GET /v1/models GET /v1/runners POST /v1/audio/speech POST /v1/audio/transcriptions POST /v1/voices/clone

08 / Registry

The site and CLI share one catalog.

tako library sync validates the remote document before atomically replacing the local cache. Offline use falls back to the last valid copy or bundled index.
