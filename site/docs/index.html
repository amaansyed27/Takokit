Build the current beta

Until signed installers are published, build Takokit from source with Rust stable and Node.js LTS.

git clone https://github.com/amaansyed27/Takokit.git
cd Takokit
cd apps/gui && npm ci && npm run build && cd ../..
cargo build --release
.\target\release\tako.exe doctor

Model references

References follow [namespace/]name[:tag][@digest]. The namespace defaults to library, and an omitted tag resolves to the Takokit-tested default.

tako pull kokoro
tako pull whisper:small
tako pull qwen3-tts:0.6b-base
tako pull library/openvoice:2
tako pull kokoro@sha256:<manifest-digest>

Legacy IDs remain aliases. For example, whisper-small and whisper:small resolve to the same storage identity and never create duplicate model files.

Pull and inspect

tako library sync
tako library models
tako library show qwen3-tts
tako pull qwen3-tts:0.6b-base
tako show qwen3-tts:0.6b-base
tako list

Run locally

tako speak "Hello from Takokit" --model kokoro
tako transcribe sample.wav --model whisper:base
tako clone reference.wav --name "My Voice" --model chatterbox --consent

Registry behavior

The companion library publishes small versioned manifests. The CLI validates the manifest digest and then downloads pinned checkpoint files directly from their upstream source. latest never means an unreviewed upstream commit; it means the newest release promoted by Takokit after compatibility checks.

  • Registry updates are cached under the Takokit home.
  • Pulls fall back to the last verified cached or bundled index when offline.
  • Set TAKOKIT_REGISTRY_OFFLINE=1 to disable network registry refreshes.
  • Set TAKOKIT_REGISTRY_URL to test another compatible registry.

Storage and deduplication

~/.takokit/
├── blobs/sha256/
├── cache/
├── manifests/registry/
├── models/
└── runners/

Model artifacts are content-addressed. Compatible Python models share one Takokit-owned dependency base per Python ABI, while model-specific adapters remain lightweight overlays.
